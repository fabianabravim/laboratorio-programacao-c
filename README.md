## 📚 Sobre a disciplina

Bem-vindo(a) ao repositório de **Laboratório de Programação**!

Este espaço foi criado para organizar os conteúdos, exemplos e atividades práticas desenvolvidos durante a disciplina de Laboratório de Programação do curso de Ciência da Computação da Universidade Vila Velha (UVV).

A proposta é desenvolver o raciocínio lógico, o pensamento computacional e as habilidades necessárias para resolver problemas utilizando algoritmos e a linguagem C.

Além da aprendizagem de programação, incentivamos a utilização do GitHub como ferramenta de organização, documentação e construção de portfólios acadêmicos e profissionais.

## 🎯 Objetivos de aprendizagem

- Desenvolver o pensamento computacional e o raciocínio lógico.
- Interpretar problemas e elaborar soluções algorítmicas.
- Compreender os fundamentos da linguagem C.
- Utilizar estruturas de decisão e repetição.
- Trabalhar com vetores, matrizes e strings.
- Desenvolver programas organizados e reutilizáveis por meio de funções.
- Aplicar boas práticas de programação e documentação.
- Utilizar o GitHub para armazenar e acompanhar a evolução dos projetos.

## 📝 Atividades práticas

As atividades propostas durante a disciplina têm como objetivo desenvolver a capacidade de interpretar problemas, elaborar algoritmos e implementar soluções utilizando a linguagem C.

Os estudantes deverão:

1. Ler e interpretar o enunciado.
2. Planejar a solução do problema.
3. Desenvolver o programa em C.
4. Compilar e testar o código.
5. Organizar os arquivos no GitHub.
6. Realizar a entrega conforme as orientações disponibilizadas no AVA.

## 🚀 GitHub como portfólio de aprendizagem

Durante a disciplina, incentivamos cada estudante a manter seu próprio repositório no GitHub.

O portfólio permitirá registrar a evolução dos conhecimentos adquiridos e apresentar os projetos desenvolvidos durante a graduação.

A organização dos códigos, a documentação e a compreensão das soluções fazem parte desse processo de aprendizagem.

## 🛠️ Ferramentas utilizadas

- **Linguagem C:** desenvolvimento dos programas.
- **OnlineGDB:** compilação, execução e testes.
- **GitHub:** armazenamento e versionamento dos códigos.
- **Visual Studio Code:** ambiente alternativo de desenvolvimento.
- **AVA UVV:** disponibilização de materiais e registro das entregas.

## 📌 Orientações importantes

- Os códigos devem ser organizados conforme as aulas.
- Os arquivos devem possuir nomes claros e descritivos.
- Os programas devem ser testados antes da entrega.
- As atividades devem respeitar os prazos estabelecidos.
- Trabalhos de terceiros devem ser devidamente identificados.
- Não devem ser publicados dados pessoais, senhas ou informações confidenciais.
- Cada estudante deverá compreender e ser capaz de explicar os códigos apresentados.
